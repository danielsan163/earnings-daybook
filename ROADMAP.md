# Earnings Daybook roadmap

## v1.1

- [x] **Theme selector** (Settings → Theme): Royal (purple with gold), Amethyst (purple), Gilded (gold), Evergreen (the original green) and Slate. Each has light and dark versions that follow the phone, and the home-screen status bar follows the theme. Source colours stay the same in every theme.
- [x] **Day notes**: an optional note on any day. Days with notes get a dot on the charts, the note shows in the tooltip, and each period's notes are listed under the chart (tap one to open that day).
- [x] **Goals**: weekly (Sunday to Saturday), monthly and yearly targets, set in Settings → Goals. Progress bars and "on pace for" on Today. Fireworks the first time a goal is reached.
- [x] **Goal reminders**: on Sundays, the 1st of the month and New Year's Day, a card on Today asks for the new period's goal, prefilled with the previous one. It stays until she sets it or taps "Not now".
- [x] **Year-over-year**: the Year chart shows a dashed line for the same months last year.

## Faster daily entry (proposed)

Ordered by time saved per day.

- [ ] **Dashboard shortcuts.** A small link button on each source row that opens that platform's earnings page (KDP Reports, ACX, Shopify admin, TikTok Seller Center, YouTube Studio Analytics, Meta Professional Dashboard). Check the number, swipe back, type it in. Defaults filled in; she can change each link in Settings.
- [ ] **Month-to-date mode per source.** Many dashboards show month-to-date totals more readily than a single day. For a source set this way, she types the month-to-date figure and the app works out today's amount by subtracting what's already logged this month. No mental maths.
- [ ] **Maths in the boxes.** Type `12.40+3.99` (e.g. US + UK marketplaces) and it adds them up when she leaves the box.
- [ ] **Open on the right day.** Most dashboards lag (KDP and YouTube often show yesterday's numbers). Option for the app to open on the oldest unlogged day, and to move straight to the next unlogged day after saving, so catching up after a few days is one continuous run.
- [ ] **Monthly-only sources.** Sources that only report monthly (often Audible/ACX, Meta) can be hidden from the daily form and asked for once a month instead (pairs with lump-sum entries below).

## Ideas for later

- [ ] **Monthly or lump-sum entries.** Several sources (Amazon KDP, Audible/ACX, YouTube, Meta) report or pay out monthly, often weeks late. Enter one amount for a whole month (or a date range) for a source; charts and forecasts spread it across the days it covers.
- [ ] **"Same as yesterday" button** per source, and one for the whole day.
- [ ] **Tax set-aside.** She picks a percentage; it shows how much to put aside this quarter, with the US quarterly estimated-tax due dates. An estimate from her own percentage, not tax advice.
- [ ] **Daily reminder.** iPhone web apps can't send notifications without a server. A README section on an iOS Shortcuts automation that opens the Daybook every evening.
